Integration Platform and Trading Service

Java-based data integration platform for AUSIEX. It integrates financial data from multiple external sources and processes XML, AVRO, JSON, TXT, CSV and PSV files. It supports client profiles, account relationships, settlement instructions, and cash and security movements through automated batch jobs and backend services.

Project overview

Developed and maintained backend services for a capital markets and trading application, focusing on financial data integration, message processing and backend application workflows.

What the platform is built to do

Financial organisations exchange information in different formats and through different systems. This platform provides integration capabilities to receive, process and exchange that information so the supported trading and operational workflows can use consistent data.

  • Client profiles: processes client-related information received from external sources.
  • Account relationships: supports data associated with client and account relationships.
  • Settlement instructions: handles information used in settlement-related workflows.
  • Cash and security movements: supports the processing of financial movement information.

Integration and processing capabilities

The resume identifies both file-based integration and event-driven processing in the project. The exact path depends on the integration or business workflow.

  • File integration: external systems are integrated through SFTP; Apache Camel is used for routing, file processing and transformation.
  • File formats: Java batch jobs process XML, AVRO, JSON, TXT, CSV and PSV files.
  • Event processing: Kafka consumers support event-driven financial data ingestion and processing.
  • Application integration: RESTful APIs connect internal applications with external financial systems.
  • Database work: JDBC, SQL and PL/SQL support data validation, reconciliation and transaction processing.

My role and contribution

As a Senior Software Engineer, my work covers backend development and integration activities across the platform.

  • Design and implement RESTful APIs for application and external-system integration.
  • Implement Kafka consumer-based event processing.
  • Develop and maintain Camel-based routing, file-processing and transformation workflows.
  • Build Java batch jobs for supported financial file formats.
  • Write JDBC-based database operations and SQL / PL/SQL queries for validation, reconciliation and transaction processing.
  • Investigate defects through debugging and root-cause analysis, resolve issues and support application maintenance.
